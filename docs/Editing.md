- A block shows rendered Markdown, and becomes a CodeMirror 6 editor when you click it. [[Rendering]]
- What is typed goes into the replica as the splice that was typed.
	- Offsets are in UTF-16 units, which is what CodeMirror and JavaScript count in. Rust's byte offsets never leave the crate.
	- Changes are applied last to first so earlier offsets stay valid, and concurrent edits merge as the typists meant.
	- Changes coming back from the graph reach an open editor as the smallest edit that turns its text into the graph's, and are marked so they are not sent again.
	- The editor reconciles against the graph's text, never against props, which can be a keystroke behind.
- Keys
	- Enter splits the block at the caret. The tail becomes the next sibling, or the first child if there are children.
	- Enter at the very start of a block with text adds an empty block before it instead, so the text, its children and the caret stay where they are.
	- Enter in an empty block outdents it instead, unless it is already at the top level, where it splits as usual.
	- Shift-Enter inserts a newline.
	- Tab and Shift-Tab indent and outdent, Backspace at the start joins the block to the one before, and Cmd-Shift-Up and Cmd-Shift-Down (Alt-Shift elsewhere) move it among its siblings.
	- The arrows move between blocks at the edges, and Escape leaves the editor.
	- A key that moves the block being edited says where editing continues before it moves it, because moving makes React remount the block.
	- A block opened by a key, Enter above all, takes focus without the browser scrolling and has CodeMirror bring the caret into view in the pane that scrolls, with room to spare. Left to itself, a new editor's focus either did not scroll at all, so the caret ran off the bottom of the pane, or scrolled by the engine's own rules.
- Selecting blocks
	- Select All (Ctrl or Cmd-A) in an editor selects the block's text, as it always did. Pressed again, with the text all selected (or an empty block), it selects the block as a block, and the editor closes. In a block that is not being edited it selects the block at once.
	- Each press after that takes in more, working upwards, and skips a step that would add nothing:
		- the block;
		- the block and its children;
		- the block and its siblings, with all their children;
		- the parent, with all of that;
		- the parent's siblings, with all their children;
		- and so on, a level at a time, until the whole entity is selected.
	- Dragging from one block to another selects the blocks between them in reading order, whichever way the drag goes. Dragging past the first or last block reaches it. A drag that starts in the block being edited and leaves it closes the editor; one that stays inside selects text, as usual.
	- A selection made by dragging grows from the block the drag started in, to the first step that holds it and more.
	- Escape, or pressing anywhere, lets go. The selected blocks are shaded with the editor's selection colour, each block's own text and not its children's, so a selected parent and child are not painted twice.
	- Tab and Shift-Tab indent and outdent the selected blocks, as one undo step, the same as in the editor for one block.
		- A block chosen along with its parent isn't acted on twice: it goes with the parent.
		- Indenting nests a run of siblings under the one before the run, so they keep their order; if nothing is before the run, none of it moves. Outdenting puts the run after its parent in the order it had.
	- Cmd-Shift-Up and Cmd-Shift-Down (Alt-Shift-Up and Alt-Shift-Down off a Mac) move the selected blocks, with their children, among their siblings, as one undo step. With nothing selected they move the block being edited, or the one that has the focus. A run of siblings moves as a run and stops when its first block reaches the end, instead of the rest passing it. Blocks don't change parent: that is what Tab is for.
		- Alt-Arrow is a Mac's word movement and Ctrl-Shift-Arrow selects words elsewhere, which is why neither is the key.
	- Backspace and Delete delete the selected blocks with their children, as one undo step. The links to what went are left in the text, and point nowhere. [[Undo]] brings them back. In an editor, and with nothing selected, they are what they were.
	- Copy and cut put the selected blocks on the clipboard as a Markdown outline, the same as in a file: `- ` bullets, children indented with a tab. A block chosen with its parent is part of it, once. It reads as text anywhere, so it can be pasted into another app.
	- Paste adds the blocks that the clipboard's text is an outline of, after the selection, among its last block's siblings, and selects them, so a second paste goes after the first. Text that isn't an outline is one block. A title line is left out, and properties are a block of their own. It is one undo step. A block that has the focus with nothing selected takes a paste after it too.
	- Cut is a copy and then a delete, so undo brings the blocks back.
	- In an editor, or any field, copy, cut and paste are the text's own: pasting copied blocks into an editor pastes the outline as text. That is not built yet.
	- Code: `View::copy_blocks` and `paste_blocks`, which read and write the same outline as a file (`outline.rs`).
	- Code: `lib/block-selection.ts` for the steps, and `selectionHandlers` in `components/editing.tsx` for the keys and the drag.
- Links
	- `[` makes `[]` with the caret inside, so `[[` makes `[[]]`. With a selection, the brackets go round it. `]` steps over a closer rather than doubling it, and Backspace in an empty pair removes both. A `[` before a word is left alone.
	- Typing in a `[[link]]`, or making a new one, offers the pages whose titles match, by the same matching as search. [[Title matching]]
	- Each entry shows the page's properties. When several pages share the title, the link written also carries the qualifiers that tell them apart: `Mercury#type(planet)`. [[Links]]
	- The list is offered when the link's name is typed in or the link is new, not when the caret merely arrives. A link already written is left alone until it is edited.
	- Down and Up, or a click, move into the list and write the entry into the link, so the text is what was chosen. Past either end is back to what was typed, and Escape with an entry chosen puts that back too.
	- Enter accepts what is written, chosen or not, and moves the caret past the brackets. Enter in a link whose list was never offered since the caret came in follows the link instead, making the page if it goes nowhere. An ambiguous link opens its [[Disambiguation]] page. [[Links to nowhere]]
	- Code: `lib/link-completion.ts` and `lib/auto-brackets.ts`.
- Every edit other than typing is a step of its own. [[Undo]]
- Leaving a block saves it.
	- The outline remembers each block's text from when editing began, and when editing moves on it tells the graph. That is when a new `[[link]]` gets an entity. [[Links to nowhere]]
- The edits live in `crates/view`, so they are tested natively, in Rust, with the same code the browser runs.
	- Edits that cannot apply change nothing. A split checks the offset is between characters before touching the text, and a merge says so when there is nothing to merge into.
