type:: property

- Another name for an entity. A link to an alias goes to the entity. [[Links]]
- Renaming an entity keeps its old name as an alias, so links written against the old name still work, including ones written on a device that was offline. [[Renaming]]
- Write it in the entity's properties block. Several can be given as a list: `alias:: [page, properties block]`.
- Aliases are matched as names are, ignoring case and spacing. Unlinked references look for them too.
