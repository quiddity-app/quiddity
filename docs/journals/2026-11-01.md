- Graph view is now framed: first visit, Reset view, and Alt-click on a node. [[Graph view]]
	- The three things the earlier entry listed as not done. The largest connected group is chosen as in the Logseq viewer, with a fall back to everything when nothing is linked.
	- Double-click on a node was the viewer's way to zoom to a neighbourhood, but here a click opens the entity and leaves the graph, so it is Alt-click instead. It has no keyboard route yet; Reset view is a button.
	- `d3-transition` is now a direct dependency for the animation. As before, I could only typecheck here; the new e2e tests have not been run.
- Graph view moved from SVG to a canvas. [[Graph view]]
	- The SVG was slow, an element per node and line, moved on each step of the layout. The canvas, the nearest-node hit-testing, repainting once per frame and not while hidden all come from the Logseq viewer. I did not take its stepped simulation loop: d3's own timer runs one step per frame already.
	- The cost was that nodes were links on the page. They are now a visually hidden list of real links beside the canvas, which keeps keyboard and screen reader use, and is not positioned so it adds nothing per step. Focusing a link highlights its node.
	- Tests used to read positions from the SVG. They now read `data-x` and `data-y` on those links, once the layout is still, and `data-view` and `data-settled` on the canvas, and click the canvas where the node is. If you add a test that needs a position, use those.
	- The backing store follows `devicePixelRatio`, which the Logseq viewer does not. Colours are the old Tailwind ones written out, and follow the system's light or dark setting.
	- Not run: the build, nor Playwright. The tests are rewritten but have never run, and dragging and the canvas sizing are the parts most likely to need a fix. I would also look at it on a graph large enough to have been slow.
- Fixed a dragged node jumping away from the pointer on the canvas. [[Graph view]]
	- d3-drag reports a drag in the subject's own coordinates, and the subject was the node, whose position is in the graph's space, not the canvas's pixels. So the node was placed using an offset from the wrong space and then followed the pointer from there. The subject is now the node's place in canvas pixels. A test checks the node is where it was grabbed, relative to the pointer, and not just that it moved.
