- In a properties block, `#key` now means the same as `key::`, and a property with no value is written `#key`.
	- Only a line that is just the key counts, so `#tag and prose` is still prose.
	- In prose a bare `#key` is still an inline property, a tag.
	- `parse_block` reads a `#key` line as an inline property, as it always did, because outside a properties block it is a tag. [[design]]
- Things worth remembering
	- A first block that is only `#todo` now counts as a properties block.
- A link to an entity that does not exist is now active. [[Links to nowhere]]
	- Saving a block makes an entity for each link it gained, and following a dangling link makes its entity. The view's `commit_block` and `follow_link` do the work, so the UI only says when a block's editing ended.
	- Going back and correcting the link before touching the entity renames it without an alias, via a new core rename that skips it. [[Renaming]]
- Property chips link to the entity that defines the property, made on first use, and a block of only properties lost its bullet. [[Properties]] [[Rendering]]
- Added the graph view, with d3 and a layout that is remembered. [[Graph view]]
	- `View::connections()` reports the entities and an edge for each pair that link, and the UI draws them and remembers where each ended up, so navigating away and back finds the graph as it was.
- Things worth remembering
	- Setting the initial zoom ends a zoom, which saved an empty layout over the remembered one before it could be restored. Nothing is saved until nodes are drawn.
	- Whether a link's old entity may be renamed is decided by it being empty: journals, property entities and alias matches all have a properties block, so they never qualify.
