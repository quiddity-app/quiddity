- Moved CI's Rust builds onto mbx, a shared build cache, including the Tauri shell.
	- The `app` job runs the shell's `cargo clippy` and `cargo test` through mbx, with the WASM build for the UI going through it too.
- Things worth remembering
	- mbx 1.29 runs build scripts through a `#!/bin/sh` wrapper. On Ubuntu that is dash, which drops environment variables whose names aren't valid shell identifiers.
	- tauri passes its core permissions to `tauri-build` as cargo metadata keyed `core:path`, `core:event` and so on, which reach it as `DEP_TAURI_CORE:PATH__...`. With the wrapper they go missing, nothing complains, and `tauri::generate_context!` panics with `SetPermissionNotFound core:path:default`. macOS's `sh` is bash, which keeps them, so it passes locally.
	- The `app` job sets `MBX_BUILD_SCRIPT_EXECUTION=0` so build scripts run directly. Compilation is still cached; build-script runs are not. Remove it when mbx stops using `sh` for the wrapper.

- Things worth remembering
	- Property lines can hide in prose: a line holding a `key:: value` code span is one when nothing before the `::` rules out a key, and is drawn as a chip. The old Properties page's first line was one. Word such lines so a colon or a link comes first.

- Link editing: bracket pairing and completion of page titles. [[Editing]] [[Links]] [[Title matching]]
	- `[` pairs, around a selection if there is one. Inside `[[ ]]` a list of matching pages appears when the link is typed in or new; arrows and clicks write the entry into the link, Enter accepts it, and Enter in a link that was never offered a list follows it.
	- Title hits now carry the page's properties and the link to write, with the qualifiers that tell it from same-titled pages, so the UI does no escaping or disambiguating of its own.
- Things worth remembering
	- Escape is the outliner's unless an entry is chosen, so it still leaves the block and saves it. A list that swallowed Escape stopped a new link's entity being made, which the tests noticed.
	- Clicking an entry only chooses it; Enter accepts. On a touch keyboard that is a tap, then Enter.
	- Playwright 1.64 wants Chromium 1248; this sandbox has 1243, and full Chromium asks for `/favicon.ico`, which the static server 404s, which the fixtures count as an error.
