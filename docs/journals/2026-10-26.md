- Made the tests earn their keep. [[Testing]]
	- `cargo nextest` runs the suite, and `cargo mutants` checks it over each pull request's changed lines in CI.
	- The mutants found real gaps in syntax, core, sync and node. Each got a stronger test or a simpler piece of code. The fuzzer found that a block's own carriage return was lost when its first bullet's properties were lifted, and the mutants showed that truncated messages were not refused.
- Built sync and a node.
	- A transport-independent protocol, tested over a simulated network, then sync over iroh and a small `quiddity-node` CLI that can also run headless.
	- Every device is equal, the headless node included. The design doc's plan for a node that acknowledges stored history was replaced for that reason. [[design]]
- Added history compaction in three layers. [[Compaction]]
	- Core got shallow snapshots and a device list in the graph, sync got compacted peers, snapshots for blank ones and vouching, and node was done the next day.
- Wrote `AGENTS.md` for the repository and each crate, for what is not obvious without reading the whole crate: git habits, writing style and the testing practice.
- Things worth remembering
	- `cargo mutants` copies the source tree, build output included, and filled the disk twice. `gitignore = true` keeps ignored files out of the copies.
	- Stacked pull requests, one commit each, fix-ups squashed, rebase and never merge.
- Built the app: a Tauri shell and a three-pane UI over the real core. [[The UI]]
	- First the shell and layout, then the UI reading the real graph over Tauri commands, then journals that scroll back and linked and unlinked references.
	- The UI got its own replica of the graph by compiling the core to WASM behind a new `crates/view`, so every query and edit is local and the shell is sent updates later. [[Editing]]
	- The outliner is a CodeMirror editor bound to a block's text, with a UTF-16 splice so typing merges as it was typed.
- Undo across the whole graph, tests in a browser, Markdown and chips, and renaming. [[Undo]] [[Rendering]] [[Renaming]]
	- Undo is Loro's, started opt in in the core and grouped by the view so a burst of typing is one step.
	- Playwright tests run against the static export, and others against `next dev`. [[Testing]]
	- Renaming keeps the old name as an alias, so old links still work.
- Added mise tasks so `mise run app` builds and launches the app, with a doctor script for what mise cannot install. [[Running the app]]
- Things worth remembering
	- Loro restores a deleted block under a new id, so nothing may hold a block id across an undo.
	- `next dev` renders on a server and the production export does not. A pane that reads the graph outside `ClientOnly` works in the export and fails in development, which only the dev tests notice.
	- `serde-wasm-bindgen` writes a missing value as `undefined` unless told to write `null`, which crashed the chips.
	- The `wasm-bindgen` crate and CLI have to be the same version exactly.
