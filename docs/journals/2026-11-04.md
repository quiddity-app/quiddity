- Fixed a round-trip failure on `main`: the export-then-import property test lost a leading newline.
	- Reading a file lifts a `title::` out of a first bullet made only of property lines, as Logseq writes them. It trimmed that bullet's blank lines even when there was no title to lift, so a block whose text began with a newline and then a property-like line came back shorter. The meta-property change made more blocks count as property lines, which is how the seed found it. Nothing is rewritten now unless a title was found.
	- The fix and a named regression test are in `crates/core/src/outline.rs`; the proptest shrank the case for us, and the CI log has it if wanted.
- Loosened a flaky graph test on the PR for [[Meta-properties]]: `openGraph` waited only the default 5s for the canvas.
	- The canvas isn't mounted until the replica has loaded, so on a busy CI runner the wait could run out before the page had anything to draw. It now waits as long as the rest of the graph spec does (20s). The failure was one test in one run; the trace wasn't inspected, so a slow load is the likeliest cause rather than a proven one.
- Corrected the graph view's sizing for dense displays. [[Graph view]]
	- The pixel-ratio handling was right (the transform is `ratio·k`, so everything is in CSS pixels); the nodes were simply too big and the labels scaled with the zoom. Radius was `4 + 2·√degree`, about twice the Logseq viewer's `max(3, 3·ln(degree+1))`, and the 10px font was in graph space, so a hub's name was still drawn at 3px on screen.
	- Text and line widths now divide the zoom out and stay the same size on screen, and a label is dropped when its node is under 5px in radius on screen. The sizes are in `lib/graph-style.ts`. The ratio is also re-read when it changes without a resize (another screen, page zoom).
	- Not run: Playwright, which can't run in the sandbox. The two new tests in `graph.spec.ts` (labels drop out and return with the zoom; a 2x display has twice the pixels) have never run, and the look of the new sizes wants checking by eye.
- Made the main entity column adaptive. [[The UI]]
	- The article's text size is `calc(1.25rem + max(0.325cqw, 0.325lvh))` and its width is capped at 50rem, so the text grows with the pane or the window height, whichever is larger. `cqw` needs a container, which an element can't be to itself, so `MainEntity` wraps the article in an `@container`.
	- The title and the block headings are `em`-sized so they follow it; side cards inherit 1rem, so they look as before. Chips and other chrome stay in `rem` on purpose.
	- Not run: typecheck and Playwright, which can't run in the sandbox (no `node_modules`, and the WASM build fails). It wants a look by eye at a few window sizes.
