- Mark a journal with `##journal(day)` instead of `type:: journal` ([#249](https://github.com/quiddity-app/quiddity/pull/249))
	- Step 5 of [[Model redesign]]. A [[Journal]] is `##journal(2026-10-25)`; creation, identity, merging and import follow it, and `type:: journal`, `date::` and the `date` property are gone. `type` now keeps one meaning, `property`. [[type]]
		- `create_journal` makes a day's journal whether or not there is one, `ensure_journal` only when there is none; duplicates are still merged by day.
		- A property entity with a `##journal` line whose day can't be read stays a property entity, since only a readable day makes a journal. An entity that is both with a good day is a journal.
		- The `date` page is deleted, so links to `[[date]]` in the docs go nowhere now; none remain.
