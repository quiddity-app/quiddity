- Added presence: who is here, and which blocks they have open. [[Presence]]
	- It is kept apart from the graph, so it leaves no history, and travels on the sync connection as one more message type.
	- A device is live if it is reachable over links that both ends list, so a device that drops takes whatever hung from it with it. There are no timers.
- Things worth remembering
	- A simulation found that gossip which only forwards news leaves some devices never hearing of others. Each link now remembers what its peer has been told, as sessions do for updates. [[Testing]]
	- Presence in the node counts connections, since two devices that dial each other at once have two.
- The All entities page is now a table of tags, words and incoming links, not a flat list of titles. [[All entities]]
	- The flat list gave no way to choose between entities, or to see which pages matter.
	- Tags are shown only where they tell apart entities with the same title, and the fewest are picked.
	- "Tags" was not defined anywhere, so it was taken to mean valueless properties plus the values of a `tags::` property. That is a reading, and `tags_in` is where to change it.
- The All entities table sorts by any column. [[All entities]]
	- Sorting is in the UI, over the rows the view reports, so it costs no new query.
