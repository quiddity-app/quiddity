- Added graph settings, starting with where the app opens. [[Graph settings]]
	- A `quiddity.toml` at the top of an imported directory sets them, and an export writes one back when anything is set. They live in a map of their own in the graph, so they sync, and one key per setting so that devices don't conflict over different ones.
	- `home` is `"journals"` (the default), `"all"`, `"graph"` or a link such as `"[[Quiddity]]"`. This site now opens on [[Quiddity]] rather than the journals, through `docs/quiddity.toml`.
	- `/` in [[The UI]] is now a redirect to home, and the journals moved to `/journals/`, which is where the Journals entrypoint goes.
	- The file is strict: an unknown key or a bad value fails the import before anything is added. That protects against typos, but means an older build can't import a newer export that has a setting it doesn't know. If that starts to matter, the export's format version in `quiddity.json` is the place to handle it.
	- There is no way to change settings in the app yet; that was left for later on purpose.
- Fixed the Windows installers in the nightly build. [[Nightly builds]]
	- The first scheduled run built everything except the two Windows apps: WiX refuses an MSI whose major version is over 255, and `2026.11.1` is. The page had said Windows installers "need numbers", which was the wrong constraint.
	- The MSI now gets `26.11.1` through `bundle.windows.wix.version`; everything else keeps `2026.11.1`.
	- Not yet run again, so the next run is the check. The page now says how to download the artifacts and install the APK.
