- Bring the Tauri shell into the Cargo workspace ([#434](https://github.com/quiddity-app/quiddity/pull/434))
	- The shell, [[The shell]], is in the Cargo workspace but not a default member, so Renovate's bumps reach its lock.
		- Its own `Cargo.lock` is gone, and its `target` is now the root's: `release.yml` collects bundles from there and `set-version.sh` updates one lock.
		- `mise run lint` and `mise run test` still treat it separately where nextest is untried on it.
	- The workspace `rust-version` is 1.100, to match `mise.toml`. Raise it with the toolchain, or Cargo will resolve dependencies for an older compiler.
	- The pre-commit job now installs the pinned toolchain too: its cargo hooks ran on the runner image's Rust, which was older than the new `rust-version`.
	- `fuzz/` keeps its own lockfile, so a transitive bump can go stale there in the same way.
