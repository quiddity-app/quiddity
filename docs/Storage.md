- What a device keeps on disk, and what it works out again.
- The [[Loro]] document is the only source of truth.
	- Text is stored in Unicode NFC. [[Unicode normalisation]]
	- A graph on disk is a directory, made by `quiddity-node init`. It holds `graph.loro`, the graph's snapshot, and `device.key`, the device's secret key. [[quiddity-node]]
	- Saving writes the whole snapshot atomically and durably: a uniquely named file is written and flushed, renamed over the old, and the directory flushed, with saves serialised. The previous snapshot is kept as `graph.loro.bak`, and loading falls back to it if `graph.loro` can't be decoded, and the app shows a [[Recovery]] screen if that fails too. It records this device in the graph's device list first, and compacts what it writes. What it records is what the snapshot held *before* this save, never what it is about to write: other devices act on the record at once, by dropping history up to it, so a write that then failed would have left them ahead of this device. The record lags one save; the history kept doesn't. [[Compaction]]
	- [[The shell]] keeps its graph the same way, in the app's data directory, or wherever `QUIDDITY_GRAPH` says. It saves after each batch of updates from the UI.
- Blobs, the bytes of [[Binaries]], are kept by hash in `blobs/` beside the snapshot, in an [[iroh-blobs]] store. They are not derived and not in the document. `unreferenced-blobs.txt` beside them is the node's record of when it first saw each file that nothing refers to, for deleting them.
- Everything else is derived.
	- The index, of names and aliases, properties, links and how each resolved, is rebuilt from the document in memory and never synced or stored. [[quiddity-core]]
	- Full-text search reads every block when asked, from the text the view keeps. [[Text search]]
	- What costs time at start and after an edit, and what is planned about it. [[Performance]]
- Planned, not built
	- The device key moves out of the graph's directory, which gains a graph ID and a node ID, and the app keeps a map of where its graphs are. [[Identity]] [[Copied graphs]]
	- A snapshot plus an append-only log of updates, compacted now and then, so that a save doesn't rewrite everything. The shell's `AGENTS.md` says when that will be needed.
	- The derived indexes and full-text search in SQLite tables, which can be rebuilt from the document at any time and are never synced.
