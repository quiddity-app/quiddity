- Coverage-guided fuzzing for Rust, with libFuzzer. https://github.com/rust-fuzz/cargo-fuzz
- The targets are `block`, `outline` and `peer`, in `fuzz/`. A crash becomes a seed and a regression test in the crate it is about. It has found bugs that 20,000 property test cases didn't. [[Testing]]
