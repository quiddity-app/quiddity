type:: library

- A typeface for code. https://www.jetbrains.com/lp/mono/
- [[The UI]] sets all monospace text in its no-ligatures build, JetBrains Mono NL (regular and bold, as `woff2` in `apps/ui/app/fonts`), so `==` and `->` read as typed. The upstream release ships that build only as TTF, so the files are converted from it; the licence (SIL Open Font Licence 1.1) is beside them. [[Design language]]
